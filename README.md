# 💳 FinApprove Pro – Intelligent Banking Decision Platform

FinApprove Pro is a Machine Learning-based banking decision platform that predicts whether a loan application is likely to be **Approved or Rejected**.

The system uses applicant information such as annual income, credit score, employment years, existing loans, loan amount, employment type and loan purpose to make its prediction.

## 🚀 Features

* Loan approval prediction
* Random Forest Classification
* Interactive prediction interface
* Exploratory Data Analysis (EDA)
* Credit score statistics
* Loan approval distribution
* Loan purpose analysis
* Employment type analysis
* Interactive data visualizations
* Model accuracy evaluation

## 📊 Dataset

The dataset contains:

* **1,500 records**
* **13 features**
* Credit Score
* Annual Income
* Employment Years
* Existing Loans
* Loan Amount
* Loan Tenure
* Employment Type
* Loan Purpose
* Loan Approval Status

## 🤖 Machine Learning Model

The project uses a **Random Forest Classifier** to predict loan approval status.

### Model Performance

**Accuracy: 93.67%**

The model analyzes multiple applicant attributes and learns patterns from historical loan data to classify applications.

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/FinApprove-Pro.git
cd FinApprove-Pro
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
